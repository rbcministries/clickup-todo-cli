## 🚀 v0.3.0-beta.1 — write, don't just read

Everything merged since `v0.1.0-beta.2` — a month of work, and the largest release yet. The first
beta could **read and triage** your ClickUp tasks. This one can **write** them: new tasks and
subtasks, comments and replies, descriptions, checklists, custom fields, renames and deletes — and
it can live in several terminal tabs at once without them drifting out of sync.

> **Why 0.3 and not 0.2?** The roadmap had Quick Updates + New Task pencilled in as `0.2` and
> mouse support + multi-tab as `0.3`. All four epics finished in the same span, so they ship
> together and the version skips ahead. Nothing is missing.

Still a **Windows** pre-release, still unsigned, still pre-1.0. Feedback of any kind — bugs,
papercuts, "this felt weird" — is exactly what we're after. 🙏

### ▶️ New here? Start here

1. Download **`clickup-todo-0.3.0-beta.1-win-x64.exe`** from the Assets below.
2. Run it. On the "Windows protected your PC" prompt, click **More info → Run anyway**
   (the build isn't code-signed yet).
3. First run walks you through setup: paste a ClickUp **personal API token**
   (ClickUp → Settings → Apps → API Token, starts with `pk_`), pick your workspace, your
   Personal Tasks list, and a refresh interval.

Nothing to install — it's a single self-contained file. Press `F1` in the app for the full,
per-screen shortcut list.
📖 Full walkthrough: [docs/beta-testing.md](https://github.com/rbcministries/clickup-todo-cli/blob/main/docs/beta-testing.md)

### ⬆️ Upgrading from beta.2? Five keys moved

Your token, settings and pinned tasks carry over — just replace the `.exe`. But muscle memory
from the last beta will miss in five places:

| You used to press | Now |
| --- | --- |
| `Space` — change status | **`Ctrl+U`** — Quick Updates: status, priority, assignees **and lists**, in one place |
| `F2` — Settings | **`F10`** — Settings. `F2` is now **Rename** (task, checklist item, tree node) |
| `Tab` — switch Task Detail tab | **`Ctrl+←` / `Ctrl+→`** |
| `Esc` / `Ctrl+Q` — instant quit | Quitting from a root view **asks first** (`F10` → *Confirm on exit* to turn it off) |
| `Ctrl+B` in Task Detail — opened the browser *and* closed the view | Keeps the task on screen (`F10` → *Detail view* to restore the old behaviour) |

### ✨ What's new

**Creating and editing — the big one**

- **`Ctrl+N` files a new task** from the list — name, assignees, description, target **list(s)**,
  due date, priority, and your own **custom fields**. On a task with children it asks whether you
  meant a task or a **subtask**.
- In Task Detail: **`Ctrl+N`** adds a comment, **`Ctrl+E`** edits the description, **`F2`**
  renames the task, **`Del`** deletes a comment, a checklist item, or a task/subtask on the Task
  Tree — always behind a confirmation.
- **Custom fields are editable in place** on the Other tab, not just readable.
- **Quick Updates (`Ctrl+U`) is complete** — status, priority, assignees, and a **List** pane that
  adds or removes the task's list membership. Works from the main list *and* Task Detail, on any
  task, whether or not it's assigned to you.

**Checklists**

A **Checklists tab** in Task Detail: create, rename and delete checklist groups and items,
`Space` toggles an item resolved, assign an item to a person, and reorder or re-parent items.

**Comments that thread, and @-mentions that work**

Reply threads render nested and you can **post a reply into a thread**. An **@-mention picker**
backs both the comment composer and the description editor, tagging real ClickUp users (not just
plain text), with names resolved from your workspace.

**Links you can actually follow**

Links in Description / Comments / Stream are underlined and live: **left-click** to follow,
**`Tab` / `Shift+Tab` + `Enter`** to walk them from the keyboard, and real **OSC-8 terminal
hyperlinks** where your terminal supports them. A ClickUp task link opens that task's detail
**inside the app** (`Esc` walks back); `Ctrl+`click has a configurable destination — browser, or a
new terminal tab.

**One task, one tab**

`clickup-todo --task <id | custom id | task URL>` opens straight into a task, in a tab **titled
with that task** — so a row of single-task tabs stays readable at a glance. From the list,
**`Ctrl+Enter`** (or `Ctrl+`click a row) parks the focused task in its own tab. The mentions feed
has its own host too (`--feed`).

**`Ctrl+O` — open any task by id, custom id, or URL**

From the list or from Task Detail. `Enter` opens it here, `Ctrl+Enter` in a new tab,
`Ctrl+Alt+Enter` in a split pane beside you.

**Several tabs, one truth**

Edits made in one tab now surface in the others within a tick, via a lightweight change-marker
channel — no more stale rows across tabs. The local cache is hardened against concurrent
processes, and the browser-style navigation history means `Esc` reliably means "back".

**Agent dispatch**

Configure **several agent providers** and pick one per dispatch. Choose where it lands — a new
**window, tab, or split pane** — with a graceful ladder down when your terminal can't do the one
you asked for. Windows Terminal **profile matching**, WezTerm / kitty / Zellij / tmux support, a
**custom launch command** for anything not auto-detected, and a working directory that follows
your `{base}/{Repository}` layout.

**Mouse, where you want it**

Double-click a row to open it, click a fold arrow to expand subtasks, click a Quick Updates row to
apply it, click the help bar at the bottom. Every click still has a keyboard equivalent.

**A Task Tree tab**

See the current task's ancestry and its children in one place, with the same badges as the main
list — and jump to any of them.

### ⚠️ Known limitations

- **Windows only.** macOS/Linux binaries aren't published yet — the remaining gate is terminal
  rendering/keybindings (#309), Gatekeeper/exec-bit packaging (#310) and a clean-machine smoke
  test (#311), tracked under #312. Token storage, terminal launch and open-in-browser are done on
  all three platforms, so **running from source works well on macOS and Linux today.**
- **Unsigned binary** → the SmartScreen prompt above is expected.
- **Mentions feed** only shows mentions on tasks **assigned to you** unless a per-Space ClickUp
  automation turns mentions into assignments — see
  [docs/mention-assignee-automation.md](https://github.com/rbcministries/clickup-todo-cli/blob/main/docs/mention-assignee-automation.md).
- **New-tab and split-pane launches need `clickup-todo` on your `PATH`.** Where no terminal can be
  launched, the command is copied to your clipboard instead.
- **Tags aren't manageable** from the app yet, and **same-field edits across two tabs** are
  last-writer-wins (ClickUp's API has no version check).
- **Keys feel sluggish?** Try `clickup-todo --driver windows` (native Win32 input). The active
  driver shows in the status line at startup.
- Pre-1.0: the config schema may still move between minors.
